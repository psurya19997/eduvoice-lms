P04 — OTP Verification
P04 · Public
OTP Verification
Route: /signup/teacher/verify
Teacher Registration
Teacher enters the 4-digit OTP sent to their email. This verifies ownership of the email address. This happens ONCE at signup only — never again on future logins.
What's on this screen
  • Step indicator: Step 2 of 3
  • Email icon and "Check your email" heading
  • Masked email address shown for confirmation
  • 4 individual OTP input boxes (auto-advance on input)
  • "Resend code" link (available after 60 seconds)
  • "Verify & Continue" button
Logic & Rules (PRD aligned)
  • OTP expires after 10 minutes (Supabase default)
  • Wrong OTP → error shown, fields cleared
  • Correct OTP → email verified → navigate to Step 3
  • Resend throttled — 60 second cooldown between resends
  • Supabase free tier: 3 OTP emails per hour limit
PRD Note: OTP verification is ONE-TIME during signup. Teacher logs in with email + password on all future logins — no OTP required again.

Teacher Only

P18 — View Submissions
P18 · Teacher
View Submissions
Route: /teacher/assignments/:id/submissions
Teacher Only
Teacher views all student submissions for a specific assignment. Shows full score breakdown for audio submissions including transcript preview, word counts, and score components.
What's on this screen
  • Filter tabs: All | Submitted | Pending (not submitted)

P21 — Submit Audio + Confirmation
P21 · Student
Submit Assignment (Audio)
Route: /student/assignments/:id/submit
Student Only
Student records and submits their audio answer. Includes a confirmation modal before final submission since resubmission is NOT allowed. Shows all available submission type tabs.
What's on this screen
  • Submission type tabs (only shows types teacher allowed)
  • Audio tab: large record button, timer, playback player
  • Submit button (disabled until recording done)
  • Confirmation modal: "This is final. You cannot resubmit."

Logic & Rules (PRD aligned)
  • Uses MediaRecorder API (native Android Chrome — no external API)
  • On confirm: audio uploaded to Supabase Storage
  • Teacher score auto-awarded instantly on submission
  • Web Speech API transcribes audio in browser → words counted → score saved
  • ONE submission per student — enforced at database level
  • No resubmission under any circumstance
PRD Note: Web Speech API (Google's free engine in Android Chrome) handles transcription. Total Score = Teacher Score + (Total Words × 1) + (Unique Words × 3)

P24 — Student Profile
P24 · Student
Student Profile
Route: /student/profile
Student Only
Student manages their account. School is shown as locked (cannot change). Class can be changed by requesting teacher approval. Clear explanation of the class change process is shown.
What's on this screen
  • Profile avatar with initials, name, class + school in header
  • Full name and phone (read-only)
